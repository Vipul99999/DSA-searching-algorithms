# Performance

Search Variants:

| Algorithm | Complexity |
|------------|------------|
| Exact Search | O(log n) |
| Lower Bound | O(log n) |
| Upper Bound | O(log n) |
| Exponential Search | O(log n) |
| Branchless Search | O(log n) |
| SIMD Search | O(log n) |

Memory Complexity:

O(1)

Cache-Aware Search:

Improves locality for large datasets.
