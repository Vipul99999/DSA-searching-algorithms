# Adaptive Universal Binary Search (AUBS)

AUBS is a modern C++20 search framework designed to unify multiple
binary-search variants under a single extensible architecture.

Features:

- Exact Search
- Lower Bound
- Upper Bound
- First Occurrence
- Last Occurrence
- Search Insert Position
- Peak Search
- Rotated Search
- Exponential Search
- Binary Search on Answer

Advanced Features:

- SIMD Search
- Branchless Search
- Cache-Aware Search
- Predictive Search

Supported Compilers:

- GCC
- Clang
- MSVC

Supported Platforms:

- Linux
- Windows
- macOS
